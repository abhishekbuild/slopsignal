# Glossary

Words this repo's code and docs use without explaining. Alphabetical.

**background** — Short for the background service worker, `entrypoints/background.ts`. The only part
of the extension that holds tokens.

**`browser`** — The promise-based extension API, imported from `wxt/browser`. A polyfill over
`chrome.*`, so `browser.storage.local.get` returns a promise.

**badge** — The small label Chrome draws on the toolbar icon. Tabcake uses one, a `•` in Butter, and
only for a page that was remembered. Set per tab, cleared on navigation and on close.

**alarm** — A `browser.alarms` timer that survives the service worker sleeping. Tabcake keeps one, to
redraw the badge when a timed pause runs out.

**blocklist** — The document of rules and groups deciding which sites are never sent, however long
you read them: webmail, chat, money, health, localhost. The defaults live in `lib/rules.ts` and apply
whenever nothing is stored, so empty storage means the defaults and never "block nothing". See
[privacy controls](../how-it-works/privacy-controls.md).

**rule** — One blocked site: a hostname, a scope, an optional note of your own, and a switch. See
**scope**.

**scope** — How far one rule reaches. `domain` blocks the host and every subdomain; `host` blocks
that one hostname. The dashboard writes and reads `domain` as `*.example.com` and `host` as the bare
hostname, so what you type is what you get. Migration from an older flat list always produces
`domain`, because narrowing a stored rule would unblock subdomains nobody asked to unblock.

**group** — Several rules under one name and one switch. Four ship with the extension — the old
default list, split so you can keep one and drop another — and you can make your own.

**pause** — Capture stopped for fifteen minutes, an hour, or until you resume. Stored as `pauseUntil`,
where `-1` means the last of those. Checked when a page is sent, so it stops the page you are already
reading.

**content script** — Code injected into a web page, with access to that page's DOM.
`entrypoints/content.ts` is Tabcake's, and it is how a page is read. See
[Page capture](../how-it-works/page-capture.md).

**Convex** — The backend platform. This extension calls nine of its functions over HTTP.

**dwell** — Time spent looking at a page, counted only while its tab is visible. Fifteen seconds is
the line between reading a page and landing on it.

**`storage.session`** — Extension storage that is cleared when the browser closes. Tabcake keeps the
per-tab capture status there under `tab:<id>`, written only by the background and read only by the
popup.

**entrypoint** — A file in `entrypoints/` that becomes a part of the extension. WXT works out what
each one is and writes the manifest.

**externally connectable** — The manifest field naming the web origins allowed to message this
extension. Ours names one, the dashboard.

**`fakeBrowser`** — WXT's in-memory implementation of the extension APIs, used by the tests. Needs
`reset()` between tests.

**JWT** — The short-lived token proving who the extension is signed in as. Lives about an hour. The
code reads its `exp` to decide when to renew.

**link code** — The one-time, two-minute secret the dashboard mints so this extension can get its own
session. See [Signing in](../how-it-works/signing-in.md).

**manifest** — `manifest.json` in the built extension, describing what it is and what it may do.
Generated by WXT from the entrypoints and the `manifest` block in `wxt.config.ts`.

**manifest key** — The public half of an RSA key in the manifest, which pins the extension's id. See
[The pinned extension id](../how-it-works/the-pinned-extension-id.md).

**MV3** — Manifest V3, the current extension platform. Its defining trait here is that the background
is a service worker that sleeps.

**the overlap** — Where the logo's two tabs meet, drawn in Ember. As the loader, the back tab
slides away and back so the overlap shrinks and grows; it replaces every spinner.

**`ponytail:` comment** — A marker for a deliberate simplification, naming the shortcut and what
should trigger replacing it. Not a TODO.

**popup** — The panel from the toolbar icon. A brand new document every time it opens.

**refresh token** — The longer-lived token that buys a new JWT. Single use: reusing one more than ten
seconds after it was retired invalidates the whole session, which is why the extension has a session
of its own.

**service worker** — The background script's runtime. Started on demand, killed when idle, with no
memory between lives.

**single-flight** — Sharing one in-progress promise between callers so a burst produces one network
call. How renewal avoids racing itself.

**unpacked** — An extension loaded from a folder rather than the Web Store, which is how this one is
loaded during development.

**WXT** — The build tool. Turns `entrypoints/` into a loadable extension and generates the manifest,
the types and the dev-mode reloading.
